# GoPCA Suite — release anchor

This branch exists only to anchor release tags. It is deliberately almost empty.

**If you arrived here by downloading "Source code (zip)" or "Source code
(tar.gz)" from a GoPCA release, this file is what you were looking for.**

GitHub generates those two archives automatically for every release, from the
tag the release points at. They are not something the publisher uploads, and
they cannot be removed — GitHub renders them on request, and the only way to
delete them is to delete the release itself. This branch keeps them small and
honest by giving them almost nothing to contain.

**GoPCA Suite's source code is not public.** Access may be granted at the
copyright holder's discretion and requires a written agreement. If you need it
for security review, research, interoperability, or evaluation, write to
devel@bitjungle.com.
